# Weather-Application-
A responsive web-based weather application that provides real-time weather information using HTML, CSS, JavaScript, and a weather API.

## Features

- Search weather by city
- Temperature and weather conditions
- Responsive design
- User-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Weather API

## How to Run

1. Clone the repository
2. Open `index.html` in a browser
